数据同步可靠缓存

数据同步可靠缓存

1. 理念

健康历史数据从设备拉到 App 后，设备侧通常不再保留。若 App 在收到回调后进程退出、入库失败或尚未落库，该条历史可能永久丢失。

可靠缓存的目标是：历史数据以「App 确认为准」完成交付，而不是「回调发出即算完成」。

核心约定：

约定 说明
App 拥有确认权 只有 App 调用 consumeReliableCacheRecord 后，才视为该条已成功接收
至少送达一次 未确认的记录，下次 startSync 会再次通过数据回调上抛，直到确认或过期清理

| 只覆盖历史数据 | 当日数据不进可靠缓存，仍按原有同步进度续传 | | 默认关闭 | 未实现确认入库的 App 请保持关闭，避免未确认记录被反复上抛 |

数据归属关系可以概括为：

设备历史数据 → SDK 本地可靠缓存 → App 入库成功并 consume → 本地副本删除
                 ↑
         未 consume：下次同步再次回调

入口：libManager.syncData

2. 功能行为

开启后：

  • 同步到历史数据时，SDK 保留本地副本
  • App 调用 consumeReliableCacheRecord 确认后，删除对应本地副本
  • 未确认的记录，在下次 startSync 时再次通过数据回调上抛
  • 当日数据不进入可靠缓存

3. 调用时机

步骤 说明
1 SDK 初始化完成，设备已连接并完成绑定 / 重连
2 首次 startSync 之前调用一次 setReliableCacheEnable(true)
3 在 startSync 的数据回调中，入库成功后调用 consumeReliableCacheRecord
4 解绑或不再需要本地副本时，调用 clearReliableCacheRecords

说明：

  • 同一进程内多次 startSync 无需重复开开关
  • 进程重启后需重新调用 setReliableCacheEnable(true)
  • 同步进行中不要切换开关
  • 过期记录由 SDK 自动清理，无需 App 额外调用

4. 接口列表

4.1 开关可靠缓存

int setReliableCacheEnable(bool enable);
参数 类型 说明
enable bool true 开启，false 关闭；默认关闭

返回：0 成功，非 0 失败。

开启后，后续 startSync 自动使用可靠缓存。关闭后不再落盘，也不再上抛未确认的本地副本；已存在的本地副本需用 clearReliableCacheRecords 清理。

4.2 查询是否已开启

bool isReliableCacheEnabled();

返回：true 已开启，false 未开启。

4.3 确认一条记录

int consumeReliableCacheRecord({
  required SyncDataType dataType,
  required int year,
  required int month,
  required int day,
  int hour = 0,
  int minute = 0,
  int second = 0,
});

确认 App 已成功接收并处理该条数据，删除对应本地副本；后续同步不再重复上抛该条。

参数 类型 说明
dataType SyncDataType 与 startSync 数据回调中的类型一致
year / month / day int 取自本次数据回调 JSON 中标识该条记录的年月日
hour / minute / second int 按日数据传 0；按次数据传完整时分秒，取值与数据回调 JSON 一致

可在数据回调内立即调用。文件尚未落盘时也可调用：返回成功并记为待确认，随后不会再写入该条副本。

返回值 说明
0 成功
5 未找到对应记录
7 类型无法映射

仅在可靠缓存开启时有效；关闭时调用无效果。

4.4 清理全部可靠缓存

int clearReliableCacheRecords();

清理当前设备的全部可靠缓存记录。不依赖开关是否开启。不影响其它设备，也不影响同步进度与当日数据续传。

返回：0 成功，非 0 失败。

5. 示例

// 设备绑定 / 重连完成后、首次同步前开启一次
libManager.syncData.setReliableCacheEnable(true);

libManager.syncData.startSync(
  funcProgress: (progress) {},
  funcData: (type, jsonStr, errorCode) {
    if (errorCode != 0 || jsonStr.isEmpty) {
      return;
    }
    final map = jsonDecode(jsonStr) as Map<String, dynamic>;
    // 将 jsonStr 入库成功后再确认
    final year = map['year'] as int? ?? 0;
    final month = map['month'] as int? ?? 0;
    final day = map['day'] as int? ?? 0;
    // 按日数据时分秒传 0；按次数据从 JSON 取完整时分秒
    libManager.syncData.consumeReliableCacheRecord(
      dataType: type,
      year: year,
      month: month,
      day: day,
      hour: 0,
      minute: 0,
      second: 0,
    );
  },
  funcCompleted: (errorCode) {},
);

// 解绑当前设备或重置时
libManager.syncData.clearReliableCacheRecords();
